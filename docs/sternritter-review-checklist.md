## 2. 人物ごとに確認すること（原作レビュー）

採用する人物について、次の順で確認します。原作の巻・話・ページと「何を確認したか」をセットで記録してください。ページが分からない場合は未記録とし、推測で補いません。

- [ ] 名前の正確な表記を確認した。
- [ ] 読みを確認した。確認できない読みは未入力とした。
- [ ] 同一人物・別名・別個体を確認した。形態や過去の姿だけで人物を分割していない。
- [ ] 騎士団所属と、分かる範囲の所属期間を確認した。過去の在籍を最新時点の在籍として扱っていない。
- [ ] 聖文字の文字と、その人物との対応を確認した。同じ文字の複数人物を許容している。
- [ ] 入れる能力名の表記・読み・種類を確認した。聖文字、完聖体、技を混同していない。
- [ ] 説明文の各事実に原作の根拠がある。生死・役職・最終状態を推測していない。
- [ ] 確認済み情報と保留情報を分けた。公式アニメ資料だけの確認を原作確認済みにしていない。

### 人物ごとの詳細記入欄（必要な人数分コピー）

```text
人物：
採用／保留／対象外：
名前・読み：
別名・同一人物の判断：
所属・適用時点：
聖文字・能力名・読み：
説明文案：
原作出典（巻・話・ページ → 確認した項目）：
未確認項目：
```

未確認項目が残っていても、確認済みの項目だけを収録する判断はできます。ただし未入力を「なし」「不明」に置き換えず、未確認の値を `verified` にしません。
