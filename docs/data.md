# キャラクターデータ

編集元は `data/characters.json` です。CLI はこのファイルを同梱して読み込み、ネットワーク接続や CSV ライブラリを必要としません。共有型は `types/characters.ts`、読み込み時の検証は `lib/validate.ts` にあります。

構造の全体像は [データ構造の ER 図](data-model.md) を参照してください。

## 今回の移行範囲

既存 CSV の73人・全18列の内容だけを移しました。人物の説明から所属を追加する処理、外部資料による追記、最新／過去の判定はしていません。対象は原作のみで、最新の基準は原作最新話までという方針ですが、今回のデータは原作最新話での校正を済ませたものではありません。

能力体系と表示分類は CSV の `tldrType` に基づきます。東仙の第二欄も外部資料によって虚の体系へ再分類していません。空欄は `unrecorded`（未入力）とし、「なし」「不明」へ意味を補完しません。出典は既存 CSV、校正状態は `needsReview`、所属・能力の時点は未入力です。巻頭歌は今回の配布データに含めません。

## 構造

- `id`: 人物の固定 ID。名称・所属・並び順の変更で変えません。今回の ID は `scripts/migration/character-ids.json` に固定しました。試作5人は同じ ID を使い、それ以外は初回割り当ての番号を使います。
- `name` / `aliases`: 表記と読み。CSV の Kana は別名も含み、原典のふりがなと断定しません。
- `memberships`: 複数所属を保持できる配列。隊番号、呼称、役職を分けます。Espada の103などは呼称としてそのまま保持します。
- `abilities`: 能力体系ごとの配列。`items` は能力・解号・武器・技の名称ごとの配列です。二つまでという制約はありません。
- `timeline`: 基準点・適用期間・表示時点・置き換える過去情報の ID と根拠。今回は全件未入力なので、時系列による選択はしません。
- `sources`: 出典と校正状態。`sourceIndex` で参照します。
- `legacyView`: CSV 由来の一覧対象・補助番号・概要表示分類。元所属などの追加で既存一覧が変わらないよう、校正前の互換表示を保持します。
- `legacySlot`: 元 CSV の対応欄。移行の情報保持と echo の第一欄選択を確認するために保持します。新しい名称を追加するときは `null` にできます。
- `displaySection`: 概要表示の第一／第二／第三区分。表示する名前は配列から取得します。元 CSV で第一欄が空、第二欄だけに技がある場合の空欄表示も維持します。

`schemaVersion` はデータ形式の版です。新しい人物を追加しても版を上げず、互換性のない形式変更時に更新します。

## 更新と検証

JSON を編集し、次を実行します。

```console
npm run typecheck
npm test
npm run pack:check
```

読み込み時とテストで版・必須項目・列挙値・ID 重複・出典参照・時点情報の根拠を検証します。名前・読み・別名・固定 ID の検索は `lib/search.ts`、表示は `lib/output.ts` に分離しました。既存のコマンド・別名・オプションは維持しています。

現在の移行検証は73人の全18列、一覧と隊番号フィルタ、全員の tldr / echo 出力を移行前と比較します。データを意図的に更新・追加する段階では、この移行確認と新しい仕様の検証を分けて更新してください。

## 移行の再現用資料

元 CSV は `test/fixtures/human.legacy.csv`、元の18列は `test/fixtures/humans.legacy.json`、移行前の表示処理は `test/fixtures/legacy-output.js` に保存しています。これらは検証用の資料であり、編集元・配布物ではありません。

`python3 scripts/migration/migrate_characters.py` で元 CSV から今回の JSON を再生成できます。Python の標準ライブラリだけを使う一度限りの移行処理で、通常の開発・CLI・CI に Python は不要です。**この再生成は現在の JSON を上書きするため、移行後の追加・修正をしたファイルには実行しないでください。**

最新情報への校正、所属・能力の変遷の追加、履歴表示の本番導入は、CSV 移行とは別の変更として扱います。

## P3 シュテルンリッター追加

原作単行本74巻までを収録範囲とし、原作の巻・話・ページの特定は当面保留です。項目ごとに異なる2サイト以上の記載を照合して採用し、原作本文の直接確認とは区別します。公式アニメサイト、Bleach Wiki、ブリーチシティのURL・見出し・確認日は各人物の `sources` に記録します。同じサイトの別ページは1サイトとして扱います。

28人を追加し、石田雨竜は既存IDへ所属と聖文字を追記しました。合計101人、騎士団の所属記録は29人です。双子は別IDで、共通名「ロイド・ロイド」の `tldr` 検索では両方を表示します。ユーハバッハ・シャズは今回保留です。

`human --sternritter` は現在の在籍者だけでなく、騎士団への所属記録がある人物を表示します。所属期間・最新状態・生死は未校正です。人物の説明はユーザー指定により公式 CHARACTER を基準にした短い要約へ更新しました。石田を含む既存人物の説明は旧CSV由来のまま保持しています。人物内の公式サイト出典の citation と notes に説明の参照見出し・確認日を記録します。説明は公式サイト1件による採用で、能力の複数サイト照合と区別します。能力の名称と文字は `tldr` の聖文字欄で表示します。名称が未入力の場合は聖文字の文字だけを表示します。

ペペの名前は公式の「ペペ・ワキャブラーダ」を採用しました。BG9・ロバートの能力名、グエナエルの能力名と読み、ドリスコール・グレミィの能力の読みは未入力です。人物名の読み、完聖体・技は新規追加していません。石田の既存能力・読みは維持しています。ジェイムズはユーザーの決定により、マスク・ド・マスキュリンと同じ S：英雄（ザ・スーパースター）を採用しました。

形式は `schemaVersion: 2` に更新しました。聖文字の文字だけを保持できるよう `schrift.value.name` の `null`（名称未入力）を許容し、非公式サイトの出典を `communityWebsite` として区別します。読みの未入力は従来どおり `unrecorded` です。読み込みは版1も受け付けます。新しいサイト出典・時点の `reviewStatus` は `needsReview` のままで、複数サイト一致を原作確認済みの `verified` として扱いません。
